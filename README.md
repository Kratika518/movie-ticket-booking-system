# Movie Ticket Booking System

A responsive and user-friendly **Movie Ticket Booking System** built to simulate an online cinema ticket reservation experience. 
This project allows users to browse movies, view details, select seats, and book tickets seamlessly.

---

##Features

-  Browse available movies
-  Interactive seat selection system
-  Book movie tickets in real time
-  View total price calculation
-  Show date and timing selection
-  Simple authentication (if implemented)
-  Responsive UI for all devices
-  Clean and modern user interface

---

##  Tech Stack

- **Frontend:** HTML, Tailwind CSS, JavaScript  , REACT.JS 
- **Backend:** Node.js / Express.js  
- **Database:** MongoDB  
- **Version Control:** Git & GitHub
